# Global Airbnb Performance Dashboard

An interactive Power BI dashboard for analyzing Airbnb listing growth, city-level market distribution, property pricing, customer reviews, ratings, and host trust indicators.

## Project Overview

The Global Airbnb Performance Dashboard explores marketplace performance across 10 cities. It brings together listing metrics, historical trends, property-type pricing, customer feedback, and host verification indicators in an interactive report.

The project demonstrates the use of business intelligence and data visualization to examine marketplace patterns and communicate findings through dashboards.

## Tools & Technologies

- **Microsoft Power BI** — dashboard development, data visualization, and interactive reporting
- **Power BI Bookmarks** — navigation between Overall Rating and Detailed Rating views

## Dashboard Features

### 1. Listing Growth Analysis

The overview page presents key marketplace indicators, including:

- Total listings
- Number of cities
- Number of hosts
- Property types
- Customer reviews

The historical trend chart explores listing growth and changes over time, including different listing categories and major market phases.

### 2. Market Share by City

This section compares Airbnb activity across 10 cities.

Key features include:

- City-level listing distribution
- Superhost and non-Superhost listing comparisons
- Cumulative market share analysis
- Identification of cities with relatively high listing concentrations

### 3. Property Pricing Analysis

The dashboard compares average prices across four property categories:

- Hotel room
- Entire place
- Shared room
- Private room

These comparisons help explore differences in average pricing across accommodation types.

### 4. Customer Ratings & Interactive Bookmarks

The report includes two rating views connected through Power BI bookmarks.

**Overall Rating**
- Provides a summarized view of customer ratings across cities.
- Helps users compare overall rating patterns.

**Detailed Rating**
- Displays individual rating dimensions:
  - Accuracy
  - Cleanliness
  - Communication
  - Location
  - Value

**Interactive functionality:** Power BI bookmarks allow users to switch between Overall Rating and Detailed Rating views within the report.

### 5. Review Frequency Analysis

This section examines reviewer activity and review frequency.

Key features include:

- Reviewer frequency distribution
- Cumulative percentage of reviewers
- Exploration of how frequently customers leave reviews

### 6. Host Trust Analysis

The dashboard presents host verification indicators to explore the distribution of verified and unverified host profiles.

## How to Explore the Project

1. Open the repository and review the dashboard screenshots.
2. Download the Power BI template file (`.pbit`).
3. Open the template in Power BI Desktop.
4. Follow any prompts to connect or configure the required data source.
5. Explore the dashboard pages and use the rating bookmarks to switch between Overall Rating and Detailed Rating views.

*Note: The template may require the original dataset or data-source configuration to display the report correctly.*
